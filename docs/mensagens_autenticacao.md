# MENSAGENS DE AUTENTICAÇÃO PADRONIZADAS

- Credenciais inválidas no login (sem revelar qual informação está correta): "Telefone ou senha incorretos. Tente novamente."
- Sessão expirada: "Esta sessão expirou. Realize seu login novamente."
- Acesso não autorizado: "Você não tem permissão para esta realizar este acesso."
- Campos de dados vazios: "Preencha os campos obrigatórios."
- Formato de telefone inválido: "O formato do telefone é inválido. Tente novamente."
- Senha repetida não é igual ao primeiro campo: "Repita a senha corretamente."
