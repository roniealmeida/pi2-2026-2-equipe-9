# AnalisaAI

Sistema de mapeamento e identificação de plantas tóxicas voltado para produtores rurais da região de Crateús.

## Funcionalidades

- Permitir cadastro para usuários e administradores;
- Permitir login para usuários e administradores;
- Permitir logout do sistema;
- Permitir a configuração de perfil de usuários;
- Permitir o envio das imagens das plantas;
- Permitir validação da imagem antes do envio;
- Permitir o processamento da foto utilizando API integrada;
- Permitir que o usuário tenha acesso ao seu histórico de imagens;
- Permitir que o administrador gerencie usuários;
- Permitir que o administrador monitore o uso do sistema;
- Utilizar modelo generativo próprio.
